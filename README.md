# Retail & E-Commerce Sales Performance Dashboard

## 📌 Project Overview
This business intelligence project transforms over 10,000 rows of raw transaction records from the classic Superstore Sales dataset into an interactive, presentation-ready executive dashboard. The primary goal is to empower inventory managers and regional directors to analyze product performance, identify peak seasonal trends, and isolate low-margin categories to optimize capital allocation.

## 📈 Business Insights Identified
* **Margin Erosion:** High sales volume in specific sub-categories masked severe profitability issues. Revenue vs. Profit discrepancy.
* **Category Dominance:** "Technology" stands out clearly as the dominant driver in the Category-wise sales distribution chart, heavily outperforming the Furniture and Office Supplies sectors.
* **Macro Seasonality Trends:** The Monthly Sales Trend line chart showcases highly cyclical demand patterns across multi-year intervals, giving supply chain managers the visibility needed to forecast seasonal stock requirements.

## 🛠️ Skills Demonstrated
* **Advanced Data Cleaning:** Built official structured data tables, normalized messy text string entries, and standardized operational date fields.
* **Feature Engineering:** Calculated customized dynamic metrics including **Profit Margin per Order** `=[@Profit]/[@Sales]`.
* **Data Aggregation:** Designed automated Pivot Tables utilizing value filters to programmatically isolate Top 5 / Bottom 3 business drivers.
* **Interactive Dashboard:** Implemented integrated visual KPI cards, dynamic trend lines, bar graphs, and interconnected multi-chart cross-filtering Slicers.

## 🚀 How to Interact with the Dashboard
1. Download the `Retail_Sales_worksheet.xlsx` file from this repository.
2. Open the file using Microsoft Excel (Desktop application recommended for macro/slicer fluid animations).
3. Navigate to the **Dashboard** sheet.
4. Click individual options within the **Region** or **Category** slicer menus on the left side to filter all visuals across the screen instantaneously.
